# FFXIV-Flask-API-Discord-bot
Pulls API from FFXIV Collect to show data 

In bot.py line 
10, 13, 15

Change the to the correct types

To get the discord bot token you will have to create your own at https://discord.com/developers and reset the token to make it visible

To get the Channel and Server ID's you will have to enable developer mode in settings.
Simply right click and copy ID after.
